# Callum Desktop

Callum 的 Electron 桌面客户端，使用 TypeScript、Vue 3 和 shadcn-vue。

客户端已通过主进程管理的 Go 服务接通文本对话，包含项目与独立对话列表、会话重命名和删除、历史消息、模型选择、流式回答、停止生成及工具审批。设置包含外观和模型分类，支持供应商与模型配置；项目支持添加、改名、删除和新建所属对话。界面不展示内部服务连接面板。调用链与资源所有权见 [架构文档](docs/architecture.md#callum-后端)。

## 环境与启动

- Node.js **26.13.0**，由 nvm 管理；npm **11.20.0**。
- 当前随附的 Go 服务只支持 macOS Apple Silicon（darwin-arm64）；桌面对话已在此平台验证。其他平台尚无配套服务程序，不能视为可用的对话客户端。
- 安装依赖需要访问 npm 注册表；首次启动或主动安装 Electron 二进制时需要访问其下载服务。

```bash
nvm use
npm ci
npm run dev
```

`npm run dev` 同时构建主进程和 preload，启动 Vue 开发服务器及 Electron 窗口。主进程和 preload 开启文件监听，界面使用热更新。开发服务器固定监听 `127.0.0.1:5173`，端口占用时明确失败，避免误连其他服务。

Electron 二进制默认在首次启动时下载。若 GitHub 下载失败，可按 [Electron 官方安装说明](https://www.electronjs.org/docs/latest/tutorial/installation) 单次使用镜像重试，不需要修改全局 npm 设置：

```bash
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npx install-electron --no
```

该写法适用于 macOS/Linux，并保留 Electron 包内的校验和验证。

Node.js 版本由 `.nvmrc` 和 `package.json` 约束。Electron 内置的 Node.js 随 Electron 管理，与本机开发环境分别管理。

## 工程结构

```text
resources/
  backend/
    darwin-arm64/callum          计划随客户端分发的 macOS arm64 Go 服务程序
src/
  main/
    index.ts                    应用入口和启动失败处理
    application.ts              装配应用级资源与窗口生命周期
    backend/                    Go 进程、stdio 请求与业务数据适配
    windows/                    窗口创建和导航限制
    ipc/                        IPC 接入、来源验证与结果构造
    security/                   本地协议、资源路径和 CSP
  preload/
    index.ts                    通过 contextBridge 暴露 DesktopApi
  renderer/
    main.ts                     Vue 入口
    app/                        根组件和页面装配
    components/layout/          应用外壳、工作内容侧栏与统一设置入口
    components/ui/              按需引入的 shadcn-vue 组件源码
    features/                   按功能组织的页面和状态
      conversation/             对话界面、草稿、模型选择和 Markdown 排版
      settings/                 设置页面与分类装配
      models/                   供应商、模型列表和配置表单
      appearance/               外观设置内容及全局主题生命周期
    lib/                        桌面桥接入口等界面基础能力
    styles/                     Tailwind 和主题变量
  shared/                       不依赖运行环境的契约与校验
tests/
  unit/                         来源策略、资源边界与通信数据测试
  e2e/                          真实 Electron 应用验证
docs/
  architecture.md               依赖方向、资源所有权与扩展方式
```

界面调用链是 **Vue → DesktopApi → preload → IPC handler → Go 服务适配层 → stdio JSON-RPC**。共享模块不反向依赖任何进程，界面不直接访问 Node.js 或 Electron。

完整说明见 [架构文档](docs/architecture.md)。

## 开发与检查命令

| 命令                   | 用途                                    |
| ---------------------- | --------------------------------------- |
| `npm run dev`          | 开发模式，启动 Electron 和热更新        |
| `npm run typecheck`    | 分别检查主进程、测试和 Vue 界面         |
| `npm run lint`         | 代码规范及跨进程导入边界检查            |
| `npm test`             | 使用 Node.js 内置测试运行器执行单元测试 |
| `npm run format:check` | 检查格式，不修改文件                    |
| `npm run format`       | 格式化文件，会修改源码和文档            |
| `npm run check`        | 类型、规范、单元测试和格式检查          |
| `npm run build`        | 类型检查并构建三个进程的产物            |
| `npm start`            | 用 Electron 打开已有构建产物            |
| `npm run test:e2e`     | 构建并在真实 Electron 中验证桌面行为    |

生产构建输出到 `out/main`、`out/preload`、`out/renderer`。`npm run build` 不生成安装包；安装格式、签名和分发方式在发布需求确定后配置。

Go 程序存放在 `resources/backend/darwin-arm64/callum`。它已作为独立程序资源放入仓库，尚未配置安装包的资源复制。后续打包时需将目标平台程序明确复制到应用资源目录、放在 ASAR 外并保留执行权限；目录位置本身不保证程序进入安装包。具体映射见 [后台程序资源约定](resources/backend/README.md)。

Electron 测试直接使用项目中的 Electron，不需要另外下载 Playwright 浏览器。测试会创建独立临时用户目录，并在退出后清理；截图和失败产物保存在忽略的 `.artifacts/` 下。

## 导航、设置与组件

- 默认显示新对话页面，侧栏提供新对话入口、文件夹式项目分组与“最近”列表；“最近”按更新时间展示未归属项目的会话，展开项目可查看缩进的所属会话，空分组显示“暂无聊天”。条目使用 13px 字号及紧凑行距，展开列表不显示聊天图标或树状连线；侧栏收起后保留图标及可访问名称。
- 底部提供统一的设置入口，当前分类为外观和模型；没有可用模型时，对话输入区提供直达模型设置的入口。
- 项目标题右侧“＋”打开“创建项目”弹窗；在弹窗中填写名称、添加本机源文件夹，再提交创建。更换文件夹不覆盖已填写的名称，取消更换保留原选择；创建后目录固定，名称仍可编辑。项目行与“最近”标题右侧的新建按钮均使用方框铅笔图标，在对应行悬停或键盘聚焦时显示，两处图标大小和右侧位置对齐；长项目名为操作区预留空间。“⋯”入口在聚焦或悬停时显示，菜单提供同款图标的新建对话、编辑项目和删除项目；项目内的新对话在首次发送时绑定。打开新对话页面不创建会话记录。
- 会话条目“⋯”菜单提供重命名和删除。人工标题由 Go 保存，自动标题不会覆盖。删除会话和项目均需确认，有未结束执行时由服务拒绝删除；删除当前会话或项目后返回独立新对话。
- 删除遵循 Go 的软删除语义：项目及其对话从列表隐藏，不删除磁盘目录和文件，也不将其对话移入独立分组。重新添加同一目录会恢复原项目及所属未删除对话。会话删除后没有回收站入口；删除会话及项目会清除本窗口内对应草稿。

- 支持跟随系统、浅色和深色主题，监听系统外观变化。
- 外观偏好保存在当前设备的页面存储中，仅包含主题枚举，不存放凭据或业务数据。
- 全局设计变量位于 `src/renderer/styles/main.css`，组件按 shadcn-vue 的源码方式维护。
- `components.json` 已配置路径。按实际需要添加组件，例如：

```bash
npx shadcn-vue@2.9.0 add button
```

执行 CLI 会下载组件并可能修改依赖，需要审查生成内容。CLI 不作为应用或常驻开发依赖安装；现有 Button 来自官方注册表，并按本项目的格式与默认属性要求调整。源码许可见 [第三方说明](THIRD_PARTY_NOTICES.md)。

## 对话与模型配置

- 输入区默认容纳两行文字，模型和发送／停止按钮位于独立的底部工具栏。文字自动换行或粘贴多行时向上增高，文本区高度上限为 12rem（默认 192px），达到上限后内部滚动。删除内容或发送清空后收缩至两行；窗口宽度变化时重新适配。Enter 发送，Shift + Enter 换行；生成时可停止，也可切换到其他对话或设置。
- 新对话的输入框上方显示项目标识和“此计算机”，首次发送或打开已有会话后隐藏整条栏。“选择项目”菜单支持名称搜索、分页加载、取消项目选择和新建项目；搜索仅作用于已加载项目，可加载更多继续搜索。项目在首次发送时绑定，此前选择不会创建会话记录；切换项目时分别恢复该项目或独立新对话的草稿。“最近”标题右侧的新建对话图标可打开独立新对话。
- 模型回答按 Markdown 排版，支持标题、强调、列表、引用、表格、网页链接和行内代码，流式输出会持续更新；用户输入按原文展示。附件上传和已有会话移动项目尚未接入。
- 双方消息下方提供复制图标：提问复制正文原文，回答复制原始 Markdown，流式回答复制点击时已输出的正文；执行状态、调用过程、图片路径及操作按钮不混入正文。成功显示“已复制”，失败可重试，空正文不提供复制操作；消息复制上限为 8 MiB UTF-8，不截断内容。
- 最新消息页的最后一条纯文本提问提供编辑入口，生成、等待审批或补充输入时禁用。编辑使用行内表单，Enter 换行，Ctrl／Command + Enter 重新发送，Escape 或“取消编辑”退出；普通输入区的草稿独立保留。首次受理前失败会保留修改供核对及重试，受理后使用新执行生成回答；已有提问 ID 和顺序保持，旧回答由服务端替换，实际工具操作与审批审计保留，不撤销已经发生的操作。切换会话退出编辑；历史分页不提供较早提问的编辑入口。连接中断时仍按结果未知处理，不自动重新发送。
- 每轮回答上方展示执行状态和用时，生成时每秒更新，完成后使用后端保存的创建/结束时间固定显示，重新打开历史不重新计时。用时包含等待审批；不到一秒会明确标注。取消、失败、断连和中断显示对应状态，缺少完整时间或恢复后的中断记录不显示推测用时。
- 回答内支持展开调用过程，按步骤顺序保留模型在工具调用前输出的说明文字，并展示文件读取、目录查看、搜索、文件编辑、命令和补充输入步骤。执行时在主消息流中直接展示思考和概述，概述之间的连续操作合成一个可折叠分组，摘要按动作统计已完成次数，并单独标注执行中、等待审批、等待补充输入、失败、取消及中断。当前操作组自动展开，进入下一模型阶段后自动收起，等待用户决定的组默认展开；各组也可手动切换。完成、失败、取消或中断后通过整轮状态与用时入口收起过程。历史及已结束过程默认收起，同一时间只展开一轮；重新展开只显示概述与分组摘要，打开分组后显示各条操作，再点击操作查看具体命令、参数及输出，同一轮仅保留一项详情，收起分组清除其详情。折叠不取消任务。工具行可查看固定参数、状态、错误、实时输出及已保存结果，批准不等于执行成功，取消不表示操作一定未生效。辅助标题和摘要模型调用不混入回答过程，图片查看不在此功能范围内。
- 随附 Go 服务统一检查 Token、消息数量与实际请求字节，长任务可自动压缩较早完整工具批次并继续。当前问题和正在执行的批次保留原文，原始步骤及真实用量保留；重启恢复摘要和未覆盖轨迹，不重放工具操作。摘要失败保留旧有效摘要，无法安全压缩的输入明确报错。历史按有界完整轮次和工具批次读取，避免旧长会话在进入压缩判断前超限。
- 随附 Go 服务在每轮主对话中引导模型先用 1～2 句话说明一组操作的目的，再调用工具，并在阶段变化时简要报告发现和下一步。前端复用现有调用过程，按“说明 → 操作 → 进展 → 操作”展示；开始阶段的文字可先流式出现，工具调用确认后归入过程，最终回答独立保存。文字来自模型，遵循程度与模型有关；未输出时不会拼接虚构进度或额外请求模型。提示计入上下文预算，压缩后仍有效，不进入标题或摘要调用。
- 长过程每次读取 50 条，运行中自动向后补齐；展开分组和详情只暂停页面滚动，不暂停新阶段或审批状态的读取，向上读取历史时暂停实时向后补齐，到达最新记录后恢复。浏览历史时在主消息区滚动自动分批读取，不显示分页按钮或窗口边界提示。新步骤先补满当前批次，展示窗口最多保留 3 批、150 条轻量概述，可通过双向滚动查看完整记录，不限制后端执行。操作组跨越窗口边界时使用“操作记录”概述，隐藏局部次数及窗口提示；记录齐全时展示实际次数，等待、失败等状态持续显示。主进程与当前会话的即时缓存最多保留 200 条步骤、约 4 Mi 字符内容，原始记录仍由 Go 持久化。滚动窗口不保留参数和输出原文，单条过程概述最多展示 16 Ki 字符，超过时标注截取；命令详情按需读取，收起后释放。单步骤参数最多展示 128 Ki 字符、即时文字最多展示 512 Ki 字符，实时输出最多 64 Ki 字符；详情最多读取 8 MiB 原始数据、展示 256 Ki 字符，截取会明确标注。命令分片不重放，重载后读取服务保存的有界最终结果；这些结果也可能包含后端的截取标志。
- 代码块显示语言标识并提供复制按钮，已按需加载 JavaScript、TypeScript、Go、JSON、Python、Shell、HTML/XML、CSS、SQL、Java 高亮；未知语言按代码原文展示，超过 20000 字符的代码块保留排版和复制但不高亮。复制只写入所选代码块的文本。
- 网页链接仅允许无账号密码的绝对 HTTP/HTTPS 地址，点击后由系统默认浏览器打开；文件、系统应用协议和相对链接不作为可打开链接。图片语法按链接展示，不自动请求远程图片。模型 HTML 不执行，排版输出还会经过允许列表清理。
- Markdown 解析与高亮由窗口共用的 Worker 承担，流式更新按界面帧合并；同一条回答持续显示已解析的有效前缀，繁忙期间仅排队最新快照。未变化的段落保留 DOM，代码高亮使用有界内存缓存。单条消息超过 256 Ki 个 JavaScript 字符、解析输出超过 2 Mi 字符或解析失败时，完整回退为文本并提示，不截断回答。公式和图表扩展尚未提供。
- 工具由后端调度。待审批时，在输入框上方展示审批卡片，展示固定操作的目标，完整快照可展开查看；无法识别的快照直接展开原文。可选择“仅本次允许”、拒绝或停止整个执行，多项请求逐项确认。提交中及断连时禁用决定，失败后保留原快照供重新核对；普通输入框保留可见并暂时禁用，停止生成按钮仍在原位；卡片右上角只收起卡片，可随时展开，不产生审批决定或取消。审批结束保留本窗口内的草稿。批准不表示工具已经成功。
- 默认 `on-request` 下，`read_file`、`list_directory`、`search_text` 可直接读取当前系统用户可读的本地路径，包括项目外路径；无项目时仍必须使用绝对路径，路径和资源校验继续生效。`always` 保留逐次审批，`never` 不询问并拒绝仍需审批的写入、命令或其他操作；只读类别不能抵消删除、外发、未知或其他影响。macOS 普通命令通过系统沙箱自动执行，命令网络关闭、写入限于项目与私有临时目录；已识别危险命令和本次沙箱外请求仍独立审批，不按命令文字伪装为读取。
- 当审批卡片提供目录选项时，可选择“本会话允许此目录”：授权覆盖真实父目录及子目录的读取和普通修改，仅对当前会话生效，后续提问及重启后保留，其他会话不继承。“仅本次允许”不会创建目录授权。写入审批展示服务端固定的实际目标及操作影响，完整记录可按需展开；客户端不从工具参数推测授权范围。
- 标题栏“权限”打开会话权限弹窗，可分页查看、刷新和撤销额外目录授权；消息区不再放置权限管理面板。历史只读授权记录保留，但默认读取不再依赖它；撤销不会禁止普通读取。撤销写授权后，依赖它的后续修改重新判断，已单独批准或开始的操作不会撤回。查询或撤销失败保留当前信息并提供重试，提交期间及断连时禁用对应操作，关闭弹窗恢复入口焦点。
- 模型可通过 Go 的 `request_user_input` 请求补充信息。问题卡片位于输入框上方，支持最多 8 个选项、自填回复、选择后补充文字及显式跳过；选择后仍需发送，Enter 发送文字、Shift + Enter 换行。回复只关联对应问题和执行，不作为工具授权；收起和切换页面保留当前窗口内的回复草稿。问题在 Go 中持久化，页面刷新后可重新查询等待中的问题；未发送的回复草稿仅存窗口内存。停止或服务退出会取消等待，异常中断恢复后不自动继续。
- 会话与执行记录由 Go 服务默认保存于 `~/.callum`，客户端不直接访问 SQLite。关闭 macOS 窗口保留服务与执行；退出应用会请求关闭服务并取消、等待其未完成执行。
- 新的服务数据目录没有模型。在“设置 → 模型”添加供应商，从“服务类型”下拉选择 Chat Completions，填写名称、API 根地址（例如 `https://api.example.com/v1`）及可选的 API Key，再添加模型展示名称、供应商实际接受的模型 ID 和供应商声明的上下文容量，并启用模型。当前支持兼容 Chat Completions 的服务。配置操作本身不调用真实模型，也不会自动发现厂商的模型列表。
- 模型选择位于输入框右下角、发送／停止按钮左侧，仅显示已启用模型。保存配置后自动同步选项，返回对话即可选择和发送，不需要刷新或重启。停用或删除模型后，后续发送需要选择可用模型；删除配置不会删除已有会话和消息。供应商仍有关联模型时不能删除。
- 供应商和模型支持新增、编辑、删除，模型可单独启用或停用。模型编辑支持填写供应商声明的上下文容量（Token），不预填推测值。随附服务的自动上下文预算依赖该配置，旧模型没有容量时请在模型设置中补充；输出容量、能力与推理等级等其他元数据仍按后端原值保留，暂不提供编辑入口。
- API Key 当前沿用已确认的 Go 服务机制，以明文保存在服务数据目录（默认 `~/.callum`）中的本地 SQLite，尚未采用系统钥匙串。编辑表单不回显原密钥：留空保留原值，填写新值替换，勾选“清除已保存的 API Key”后保存才清除。密钥不写入页面存储、配置查询结果或客户端日志，表单关闭时清理其临时状态。
- 不会自动复制 Go 源码仓库的数据库或凭据，也不能同时启动两个服务占用同一目录。
- 单条输入限制为 100000 个 JavaScript 字符；消息历史每页 50 条，可向前翻页并回到最新消息。界面最多保留 200 条消息、约 4 Mi 字符的正文窗口；更早内容仍在后端。项目、独立对话及每个项目的对话各按每页 50 条加载、各最多 1000 条；项目对话仅在展开时查询，窗口最多缓存 20 个分组，超出后移除较早的分组缓存，后端记录与草稿保留。草稿在会话、各项目的新对话及独立新对话之间隔离，仅保存在本次窗口内存中，最多 100 份，关闭或刷新页面会丢失。
- 流式更新按会话、执行和消息归属，完整消息替换中间文本。断连、超时或落库失败不会作为执行成功，也不会自动重发请求；应重新打开应用核对历史。

自动化验证使用真实 Go 程序和独立临时数据库，模型端使用本机受控 HTTP 响应，覆盖配置增删改、凭据保留与清除、配置后发送，以及流式、并行隔离、取消、失败、审批及恢复。这些检查不代表已经验证真实模型厂商的兼容性。

## 数据目录与通信边界

Go 服务在开发、本地构建预览和发布运行时默认使用家目录下的 **`~/.callum`**，主进程根据系统家目录计算绝对路径并通过 `--data-dir` 传入，不依赖 Shell 展开 `~`。对话、模型配置及相关业务数据保存在此处；可执行程序仍位于客户端资源／安装目录。

Electron 的缓存与外观偏好独立保存：开发及本地构建预览使用系统应用数据位置下的 `Callum Development` 目录，发布安装后的应用使用 Electron 对应的用户数据目录。

旧的 `Callum Development/backend`（或原发布应用 `userData/backend`）原样保留，本次不自动迁移、合并或删除。切换后读取 `~/.callum` 已有数据；目标目录没有模型时，需要在设置中重新配置。已有数据的格式兼容性与升级由 Go 服务管理。同一目录不能同时由桌面客户端和另一个独立 Go 服务使用。

开发或自动化验证需要隔离数据时，可以设置 **绝对路径** 的 `CALLUM_USER_DATA_DIR`。设置后，Electron 使用该目录，Go 服务使用其下的 `backend` 子目录，**不访问默认的 `~/.callum`**。应用按需要创建目录，不会自动删除；自动化测试负责创建及清理自己的目录。该隔离优先级在开发和发布运行时一致，新建服务数据目录权限为 `0700`，不改变已有目录权限。

```bash
CALLUM_USER_DATA_DIR=/absolute/path/to/isolated-profile npm run dev
```

上面的环境变量写法适用于 macOS/Linux；Windows PowerShell 使用 `$env:CALLUM_USER_DATA_DIR = 'C:\absolute\path\to\profile'` 后运行命令。

发布页面通过 `callum://app/` 加载，只服务构建后的界面资源。窗口启用沙箱与上下文隔离；IPC 校验所属窗口、主框架、页面来源和参数。新窗口、外部导航及页面权限默认拒绝。发布 CSP 不允许界面发起网络连接；对话通过主进程的专用适配层访问本地 Go 服务，模型网络请求由 Go 持有。消息解析 Worker 只允许加载同源构建资源，不放宽页面网络或脚本执行策略。

### 命令沙箱与默认权限

会话右上角“权限”可读取、保存所有会话后续任务的默认设置：访问范围支持项目自动（workspace-write）和只读（read-only），审批方式支持按需、每次、不询问并拒绝仍需审批的操作。保存使用服务端 revision，冲突或失败后需重新读取核对；已经受理或等待审批的任务保留其原权限快照。额外目录授权仍只属于当前会话，不能替代命令提权。

随附 darwin-arm64 服务通过 macOS Seatbelt 约束命令与子进程，允许读取当前用户可读路径，写入仅限项目与每次命令的私有临时目录，命令网络关闭。未绑定项目时不开放项目写入。已识别危险命令经确认后仍在沙箱内；明确请求 require_escalated 的审批卡说明“本次沙箱外运行”，批准只针对固定命令本次使用当前系统用户的文件及网络权限，拒绝不执行。沙箱失败不自动提权重试。模型端点请求不受命令沙箱网络限制。

Seatbelt 使用共享文件系统，既有硬链接及可写别名仍共享文件内容；它不创建独立文件副本。其他平台后端尚未接入相同系统沙箱，仍需命令审批。旧配置缺少 sandbox_mode 时只为新任务采用 workspace-write，历史权限快照、审批和操作记录不改写；无数据库结构迁移。完整边界和进程生命周期见 Go 仓库 README。

### 对话过程与滚动

流式回答平滑跟随底部；向上滚动、触摸阅读或使用向上翻页键时停止跟随，可点击“回到最新消息”恢复。系统开启减少动态效果时直接定位。

每轮状态和横线统一位于该轮思考、阶段说明与回答正文之前。运行时状态入口不折叠，思考和操作按顺序直接展示；结束后在同一位置切换为状态与整轮用时的折叠入口。分隔线固定在状态标题下方，运行、结束、展开与收起时均保留；标题使用对话字号和淡灰文字，细小右箭头位于文字右侧。鼠标悬停或键盘聚焦时显现收起状态的箭头，展开时箭头朝下并保持显示；触摸设备始终显示箭头。点击标题或使用 Enter／空格切换，内容带高度和透明度过渡，减少动态效果时关闭动画。工具参数与输出按需读取，收起完成后释放详情；迟到的查询不会重新打开过程。

上下文压缩在实际发生的位置展示独立浅灰状态行，使用细线压缩图标，不进入工具操作分组、计数或详情折叠。相邻压缩批次合并显示：运行时为“正在压缩上下文 · 可能需要几分钟”，所有已加载批次完成且来源明确为自动触发时为“上下文已自动压缩”。手动压缩或来源不明的旧记录显示“上下文压缩已结束”，避免把无操作结果或未知来源标为自动压缩成功。失败、取消、中断和断连按实际状态显示；断连或执行已结束但步骤尚未确认时停止加载动画，不推断成功。历史重新展开或重载后复用步骤状态与触发来源，摘要模型正文不进入阶段说明。

供应商实际返回推理文本时显示带流光的“思考中”，运行中直接展示且不提供手动折叠按钮；思考步骤结束后显示“已思考”并默认收起。思考文本采用淡色正文，预览最高 140px，超出后可滚动，非边缘位置显示渐隐。未提供独立思考耗时，不将模型请求总耗时充作思考耗时；整轮用时仍使用服务端执行时间。取消和失败保留已收到的部分内容并明确提示。切换会话或重载后可从持久化步骤恢复；缺少字段的旧记录不显示空面板。推理预览沿用有界概述窗口，过长时提示截取；完整记录保留在服务中。不从正文标签猜测或生成推理。

Electron 端到端测试默认设置 `CALLUM_TEST_BACKGROUND=1`，在隔离数据目录中保持窗口隐藏，不主动聚焦；macOS 同时隐藏测试应用的 Dock 图标。该开关只在非打包应用且显式提供 `CALLUM_USER_DATA_DIR` 时生效。后台测试禁用渲染进程后台节流以验证流式更新，不更改正常启动行为。
