# 功能与交互

本文记录桌面客户端已接通的功能和交互边界。界面不展示内部服务连接面板。环境与运行方式见 [桌面端开发](development.md)，组件及状态实现见 [桌面端架构](architecture.md)，Go 协议适配见 [Go 服务接入](backend-integration.md)。

## 导航、设置与组件

- 应用启动时显示全窗口 loading 页“正在加载 Callum…”，等待应用信息、服务就绪以及初始项目、对话和执行设置读取完成后自动进入主界面。Go 服务启动失败时显示全窗口“Callum 启动失败”、安全的失败原因和“重试启动”按钮，主界面与设置入口均隐藏。原因区分服务程序缺失、执行权限、数据目录、启动超时、握手失败、已知的数据目录占用及就绪前退出；无法识别的内部错误只展示启动阶段信息，不转发原始诊断。按钮支持键盘操作，失败时聚焦按钮；重试期间回到 loading，重复提交共享一次启动。重试成功后重新读取初始业务数据，再次失败仍可重试。服务正常关闭时切换为“正在关闭…”，隐藏侧栏、对话、输入框和设置弹窗。loading 和失败页跟随明暗主题，支持小窗口与长原因；loading 遵循系统“减少动态效果”。界面切换保留根组件持有的会话和草稿，窗口关闭或刷新仍遵循既有草稿生命周期。运行中断连保留现有会话、部分回答和明确错误，不能通过启动重试重启服务，也不自动重发请求。
- 默认显示新对话页面，侧栏提供新对话入口、文件夹式项目分组与“最近”列表。点击“项目”或“最近”的标题可独立展开和收起分组，两组默认展开，重新展开“项目”会恢复之前打开的项目。分组和项目下的会话列表通过高度与淡入淡出过渡收放，启用系统“减少动态效果”时立即切换。“最近”展示未归属项目的会话，置顶优先，其余按更新时间倒序。展开项目可查看缩进的所属会话，空分组显示“暂无聊天”。条目使用 13px 字号及紧凑行距，展开列表不显示聊天图标或树状连线。侧栏收起后保留图标及可访问名称。
- 底部提供统一的设置入口，当前分类为外观和模型；没有可用模型时，对话输入区提供直达模型设置的入口。
- 悬停项目或会话约 450ms 后，在条目旁显示信息卡片，鼠标移入后可继续操作。项目卡片展示名称、主要目录及其他源目录，并提供置顶和编辑入口；路径将当前用户目录缩写为 `~`，过长时单行省略，悬停或键盘聚焦可查看完整绝对路径。会话卡片展示完整标题、更新时间及已绑定的项目。聚焦条目后按右方向键可进入卡片，Esc 关闭并返回原条目。卡片支持明暗主题、窗口边缘避让和系统“减少动态效果”。侧栏项目与最近共用的滚动区采用 6px 透明轨道滚动条，滑块在滚动时显示，停止后淡出。
- 项目标题右侧“＋”打开“创建项目”弹窗；在弹窗中填写名称即可创建独立项目，也可通过底部“添加文件夹”选择最多 16 个本机源文件夹，每行右侧的 × 解除目录关联。默认将首个文件夹设为“主要”，悬停文件夹行或键盘聚焦行内控件时显示右侧“设为主要”按钮，点击可切换主要目录，并立即排到源文件夹列表首行，其余目录保留原有相对顺序；仅主要目录显示标记，完整路径通过悬停提示查看。取消系统选择保留已填名称和目录。项目行与“最近”标题右侧的新建按钮均使用方框铅笔图标，在对应行悬停或键盘聚焦时显示，两处图标大小和右侧位置对齐；长项目名为操作区预留空间。项目“⋯”入口在聚焦或悬停时显示，从按钮下方打开菜单，提供置顶／取消置顶、编辑、归档项目和移除项目；新建对话使用项目行右侧图标。项目列表置顶优先，其余按更新时间倒序；置顶不切换当前会话。项目内的新对话在首次发送时绑定，打开新对话页面不创建会话记录。
- 最近及项目内的会话在悬停或键盘聚焦时显示置顶和归档快捷按钮。置顶和取消置顶在原分组内排序，并保留当前会话。右键会话行或聚焦后按 `Shift+F10` 可打开菜单，执行重命名、置顶、归档和删除。过长的会话标题在悬停时横向滚动一次，末尾短暂停留后复位。系统启用“减少动态效果”时，完整标题仍可通过悬停提示查看。双击会话标题可重命名，双击项目名称可编辑项目并保留展开状态。编辑弹窗会聚焦并全选名称，取消保留原名称，保存失败保留输入，关闭后恢复入口焦点。人工标题由 Go 保存，并优先于自动标题。
- 项目编辑弹窗可改名，也可通过已有源文件夹右侧的“设为主要”按钮切换主要目录，按钮在悬停文件夹行或键盘聚焦行内控件时显示，主要目录始终排在首行。底部“添加文件夹”可继续追加源目录，每行 × 可移除目录；移除主要目录时自动选剩余首项，移除全部目录后仍可保存项目。保存时名称、主要目录和完整目录列表一起提交，取消保留原设置，保存失败保留输入与目录选择。保存会复核原目录快照，目录已被其他调用方修改时提示重新编辑。目录移除只解除关联，磁盘文件、项目标识和已有对话保留。后续相对路径以新主目录为基准；无目录时使用绝对路径。有未结束执行时拒绝目录变更，目标与其他项目主目录冲突时拒绝保存。底部提供“移除本地项目”、取消和保存按钮。“移除本地项目”进入现有删除确认，默认聚焦取消。删除会话和项目均需确认，有未结束执行时由服务拒绝删除；删除当前会话或项目后返回独立新对话。
- 侧栏底部“已归档”打开归档弹窗，通过“会话”和“项目”页签查看、刷新、分页及恢复。会话归档保留原文、项目归属、置顶状态及本窗口草稿，恢复后回到原分组；归档当前会话后返回独立新对话。项目归档隐藏项目及其所属会话，保留目录、文件、置顶状态和本窗口草稿，恢复后重新显示原项目及所属未单独归档的会话；单独归档的会话仍在会话页签恢复。项目存在活动执行或会话正在执行时不能归档，失败保持原状态。归档、恢复和置顶由 Go 持久化，应用重启后保留；草稿仍只保留在当前窗口。归档读取或恢复失败可重试，断连时显示错误并禁用修改。
- 删除遵循 Go 的软删除语义：项目及其对话从列表隐藏，不删除磁盘目录和文件，也不将其对话移入独立分组。重新添加同一主目录会恢复原项目及所属未删除对话，其他目录以本次选择为准。会话删除后没有回收站入口；删除会话及项目会清除本窗口内对应草稿。

- 支持跟随系统、浅色和深色主题，监听系统外观变化。
- 外观偏好保存在当前设备的页面存储中，仅包含主题枚举，不存放凭据或业务数据。
- 全局设计变量位于 `src/renderer/styles/main.css`，组件按 shadcn-vue 的源码方式维护。`popover` 背景及文字颜色在主题和 Tailwind 中显式映射，菜单使用不透明白底／深底、14px 字号、圆角边框及阴影，靠近窗口边缘时自动避让；键盘方向键、回车和 Escape 沿用可访问菜单行为。
- `components.json` 已配置路径。按实际需要添加组件，例如：

```bash
npx shadcn-vue@2.9.0 add button
```

执行 CLI 会下载组件并可能修改依赖，需要审查生成内容。CLI 不作为应用或常驻开发依赖安装；现有 Button 来自官方注册表，并按本项目的格式与默认属性要求调整。源码许可见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

## 对话与模型配置

- 输入区默认容纳两行文字，模型和发送／停止按钮位于独立的底部工具栏。文字自动换行或粘贴多行时向上增高，文本区高度上限为 12rem（默认 192px），达到上限后内部滚动。删除内容或发送清空后收缩至两行；窗口宽度变化时重新适配。Enter 发送，Shift + Enter 换行；生成时可停止，也可切换到其他对话或设置。
- 新对话的输入框上方显示项目标识和“此计算机”，首次发送或打开已有会话后隐藏整条栏。“选择项目”菜单支持名称搜索、分页加载、取消项目选择和新建项目；搜索仅作用于已加载项目，可加载更多继续搜索。项目在首次发送时绑定，此前选择不会创建会话记录；切换项目时分别恢复该项目或独立新对话的草稿。“最近”标题右侧的新建对话图标可打开独立新对话。
- 模型回答按 Markdown 排版，支持标题、强调、列表、引用、表格、网页链接和行内代码，流式输出会持续更新；用户输入按原文展示。附件上传和已有会话移动项目尚未接入。
- 悬停消息或用键盘聚焦操作时显示复制图标。提问复制正文原文，回答在生成结束后才提供复制入口，可复制原始 Markdown。手动停止后可复制已保留的正文。执行状态、调用过程、图片路径及操作按钮不混入正文。成功显示“已复制”，失败可重试，空正文不提供复制操作。消息复制上限为 8 MiB UTF-8，不截断内容。
- 消息操作栏右侧以浅灰色显示时间，随操作栏悬停或键盘聚焦展示；回答生成期间隐藏。当天只显示时分，过去 1～6 天显示星期和时分，更早显示月日及时分，跨年补充年份；以设备本地时区计算。悬停或聚焦时间可查看包含秒的完整日期时间。提问采用服务端发送时间，成功回答采用完成时间；缺少完成时间的记录明确显示已保存的“创建时间”，时间缺失则不显示。
- 最新消息页的最后一条纯文本提问提供编辑入口，生成、等待审批或补充输入时禁用。编辑使用行内表单，Enter 换行，Ctrl／Command + Enter 重新发送，Escape 或“取消”退出；普通输入区的草稿独立保留。首次受理前失败会保留修改供核对及重试，受理后使用新执行生成回答；已有提问 ID 和顺序保持，旧回答由服务端替换，实际工具操作与审批审计保留，不撤销已经发生的操作。切换会话退出编辑；历史分页不提供较早提问的编辑入口。连接中断时仍按结果未知处理，不自动重新发送。
- 每轮回答上方展示执行状态和用时，生成时每秒更新，完成后使用后端保存的创建/结束时间固定显示，重新打开历史不重新计时。用时包含等待审批；不到一秒会明确标注。取消、失败、断连和中断显示对应状态，缺少完整时间或恢复后的中断记录不显示推测用时。
- 回答内支持展开调用过程，按步骤顺序保留模型在工具调用前输出的说明文字，并展示文件读取、目录查看、搜索、文件编辑、命令和补充输入步骤。执行时在主消息流中直接展示思考和概述，过程说明使用正文色。单条操作直接显示为可展开的一行，连续多项操作合成可折叠分组。工具行使用淡色并显示短命令、文件名或搜索词，长文字省略。分组标题按顺序显示完成的动作类型，同类动作只显示一次。等待审批、失败等状态单独标注。当前操作组自动展开，进入下一模型阶段后自动收起，等待用户决定的组默认展开；各组也可手动切换。完成、失败、取消或中断后通过整轮状态与用时入口收起过程。历史及已结束过程默认收起，同一时间只展开一轮；重新展开时显示概述、单条操作和多项分组摘要。点击操作行查看详细命令、参数、输出和审核理由，同一轮仅保留一项详情，收起分组清除其详情。折叠不取消任务。工具行可查看固定参数、状态、错误、实时输出及已保存结果，批准不等于执行成功，取消不表示操作一定未生效。辅助标题和摘要模型调用不混入回答过程，图片查看不在此功能范围内。
- 长任务中的自动压缩显示独立状态，手动压缩使用输入框的 `/compact`；历史消息和原始工具记录仍可查询。预算、摘要与恢复由 Go 服务负责，接入约定见 [上下文、推理与过程说明](backend-integration.md#上下文推理与过程说明)。
- 调用过程按“说明 → 操作 → 进展 → 操作”展示模型输出；开始阶段的文字可先流式出现，工具调用确认后归入过程，最终回答独立保存。说明来自模型，遵循程度与模型有关；未输出时不会拼接虚构进度或额外请求模型。提示与协议衔接见 [Go 服务接入](backend-integration.md#上下文推理与过程说明)。
- 长过程每次读取 50 条，运行中自动向后补齐；展开分组和详情只暂停页面滚动，不暂停新阶段或审批状态的读取，向上读取历史时暂停实时向后补齐，到达最新记录后恢复。浏览历史时在主消息区滚动自动分批读取，不显示分页按钮或窗口边界提示。新步骤先补满当前批次，展示窗口最多保留 3 批、150 条轻量概述，可通过双向滚动查看完整记录，不限制后端执行。操作组跨越窗口边界时使用“操作记录”概述，省略局部状态数量及窗口提示，等待、失败等状态持续显示。主进程与当前会话的即时缓存最多保留 200 条步骤、约 4 Mi 字符内容，独立推理与参数、正文和输出共同计入容量，原始记录仍由 Go 持久化。滚动窗口仅保留最长 240 个 UTF-16 代码单元的操作标签，参数和输出原文按需读取。单条过程概述最多展示 16 Ki 字符，超过时标注截取；命令详情按需读取，收起后释放。展开命令后以浅底代码块显示完整命令和输出，下方简洁显示退出码和“原始记录”入口。运行中展示实时片段，结果落库后显示标准输出，并单独标记标准错误，无输出、二进制及截取按实际结果提示。“原始记录”包含工作目录、参数和结果，可从服务重新读取；读取失败时可直接重试。单步骤参数最多展示 128 Ki 字符、即时文字最多展示 512 Ki 字符，实时输出最多 64 Ki 字符；详情最多读取 8 MiB 原始数据、展示 256 Ki 字符，截取会明确标注。命令分片不重放，重载后读取服务保存的有界最终结果；这些结果也可能包含后端的截取标志。
- 代码块显示语言标识并提供复制按钮，已按需加载 JavaScript、TypeScript、Go、JSON、Python、Shell、HTML/XML、CSS、SQL、Java 高亮；未知语言按代码原文展示，超过 20000 字符的代码块保留排版和复制但不高亮。复制只写入所选代码块的文本。
- 网页链接仅允许无账号密码的绝对 HTTP/HTTPS 地址，点击后由系统默认浏览器打开；文件、系统应用协议和相对链接不作为可打开链接。图片语法按链接展示，不自动请求远程图片。模型 HTML 不执行，排版输出还会经过允许列表清理。
- Markdown 解析与高亮由窗口共用的 Worker 承担，流式更新按界面帧合并；同一条回答持续显示已解析的有效前缀，繁忙期间仅排队最新快照。未变化的段落保留 DOM，代码高亮使用有界内存缓存。单条消息超过 256 Ki 个 JavaScript 字符、解析输出超过 2 Mi 字符或解析失败时，完整回退为文本并提示，不截断回答。公式和图表扩展尚未提供。
- 工具由后端调度。待审批时，在输入框上方展示审批卡片，展示固定操作的目标，完整快照可展开查看；无法识别的快照直接展开原文。可选择“仅本次允许”、拒绝或停止整个执行，多项请求逐项确认。提交中及断连时禁用决定，失败后保留原快照供重新核对；普通输入框保留可见并暂时禁用，停止生成按钮仍在原位；卡片右上角只收起卡片，可随时展开，不产生审批决定或取消。审批结束保留本窗口内的草稿。批准不表示工具已经成功。
- 输入框左侧的审批菜单提供“请求批准”“帮我审批”和“完全访问权限”。切换成功后将用于所有后续任务，已受理任务继续使用各自的设置快照。退出完全访问时恢复工作区沙箱和按需审批。
- “请求批准”由用户处理需要确认的操作。“帮我审批”使用本轮模型独立审核符合范围的项目内普通文件操作、低风险的只读沙箱命令及项目内单层目录创建，审核结论与理由可在工具详情查看。高风险操作、无法确定的操作和审核失败时会交由用户决定。审核调用最多等待 20 秒，手动审批继续等待用户决定或执行取消。
- “完全访问权限”允许命令按当前系统账户权限访问文件和网络，常规操作无需逐次审批。内置文件工具仍有路径和应用数据校验，历史拒绝和结果待核实的操作继续受限。
- 文件访问和命令权限由 Go 服务判定。默认本地读取可自动执行，未绑定项目目录时使用绝对路径；命令审批显示服务端固定的只读、项目写入或沙箱外边界。具体字段、平台差异与后端策略文档位置见 [执行设置与审批边界](backend-integration.md#执行设置与审批边界)。
- 当审批卡片提供目录选项时，可选择“本会话允许此目录”：授权覆盖真实父目录及子目录的读取和普通修改，仅对当前会话生效，后续提问及重启后保留，其他会话不继承。“仅本次允许”不会创建目录授权。写入审批展示服务端固定的实际目标及操作影响，完整记录可按需展开；客户端不从工具参数推测授权范围。
- 标题栏“权限”打开会话权限弹窗，可分页查看、刷新和撤销额外目录授权；消息区不再放置权限管理面板。历史只读授权记录保留，但默认读取不再依赖它；撤销不会禁止普通读取。撤销写授权后，依赖它的后续修改重新判断，已单独批准或开始的操作不会撤回。查询或撤销失败保留当前信息并提供重试，提交期间及断连时禁用对应操作，关闭弹窗恢复入口焦点。
- 模型可通过 Go 的 `request_user_input` 请求补充信息。问题卡片位于输入框上方，支持最多 8 个选项、自填回复、选择后补充文字及显式跳过；选择后仍需发送，Enter 发送文字、Shift + Enter 换行。回复只关联对应问题和执行，不作为工具授权；收起和切换页面保留当前窗口内的回复草稿。问题在 Go 中持久化，页面刷新后可重新查询等待中的问题；未发送的回复草稿仅存窗口内存。停止或服务退出会取消等待，异常中断恢复后不自动继续。
- 会话与执行记录由 Go 服务默认保存于 `~/.callum`，客户端不直接访问 SQLite。关闭 macOS 窗口保留服务与执行；退出应用会请求关闭服务并取消、等待其未完成执行。
- 新的服务数据目录没有模型。在“设置 → 模型”添加供应商，从“服务类型”下拉选择 Chat Completions，填写名称、API 根地址（例如 `https://api.example.com/v1`）及可选的 API Key，再添加模型展示名称、供应商实际接受的模型 ID 和供应商声明的上下文容量，并启用模型。当前支持兼容 Chat Completions 的服务。配置操作本身不调用真实模型，也不会自动发现厂商的模型列表。
- 模型选择位于输入框右下角、发送／停止按钮左侧，仅显示已启用模型。保存配置后自动同步选项，返回对话即可选择和发送，不需要刷新或重启。停用或删除模型后，后续发送需要选择可用模型；删除配置不会删除已有会话和消息。供应商仍有关联模型时不能删除。
- 供应商和模型支持新增、编辑、删除，模型可单独启用或停用。模型编辑支持填写供应商声明的上下文容量（Token），不预填推测值。随附服务的自动上下文预算依赖该配置，旧模型没有容量时请在模型设置中补充；输出容量、能力与推理等级等其他元数据仍按后端原值保留，暂不提供编辑入口。
- API Key 由 Go 服务加密保存在本地 SQLite，主密钥保存在系统凭据库；系统凭据不可用时明确失败。旧明文在启动时迁移，不删除原有会话数据。编辑表单不回显原密钥：留空保留原值，填写新值替换，勾选“清除已保存的 API Key”后保存才清除。密钥不写入页面存储、配置查询结果或客户端日志，表单关闭时清理其临时状态。
- 不会自动复制 Go 源码仓库的数据库或凭据，也不能同时启动两个服务占用同一目录。
- 单条输入限制为 100000 个 JavaScript 字符；历史每页最多 25 个完整执行及所属消息，也包含独立手动压缩；可以继续向前翻页并回到最新消息，压缩没有消息时仍可继续翻页。界面最多保留 200 条消息、约 4 Mi 字符的正文窗口，按整轮保留；更早内容仍在后端。项目、独立对话及每个项目的对话各按每页 50 条加载、各最多 1000 条；项目对话仅在展开时查询，窗口最多缓存 20 个分组，超出后移除较早的分组缓存，后端记录与草稿保留。草稿在会话、各项目的新对话及独立新对话之间隔离，仅保存在本次窗口内存中，最多 100 份，关闭或刷新页面会丢失。
- 流式更新按会话、执行和消息归属，完整消息替换中间文本。断连、超时或落库失败不会作为执行成功，也不会自动重发请求；应重新打开应用核对历史。

自动化验证使用真实 Go 程序和独立临时数据库，模型端使用本机受控 HTTP 响应，覆盖配置增删改、凭据保留与清除、配置后发送，以及流式、并行隔离、取消、失败、审批及恢复。这些检查不代表已经验证真实模型厂商的兼容性。

### 命令审批与权限展示

会话右上角“权限”管理后续任务的默认设置。项目写入模式允许项目内普通补丁自动执行，只读模式下文件修改需要审批。macOS 使用 Seatbelt，Windows 已接入 AppContainer 原生沙箱实现。普通只读命令自动执行，项目写入需单次审批，沙箱外请求单独审批。保存使用服务端 revision，已受理任务继续采用各自的设置快照。

Windows 原生启动、隔离边界和桌面联调尚待实机验收。权限范围以服务端快照展示，客户端不设置或回收文件权限；字段转换和平台差异见 [Go 服务接入](backend-integration.md#执行设置与审批边界)，沙箱内部实现与恢复日志由后端专题文档维护。

审批卡按 Go 返回的固定边界区分只读沙箱、沙箱内项目写入和沙箱外执行。Windows 卡片另列固定可读目录。项目写入卡列出真实可写目录，提示本次命令可能修改或删除项目文件。沙箱内命令的网络关闭，沙箱外命令使用当前系统用户的权限。

桌面资源目录已同步采用上述权限规则和数据库基线的 Go 程序。联调使用隔离数据目录。

### 对话过程与滚动

流式回答平滑跟随底部；向上滚动、触摸阅读或使用向上翻页键时停止跟随，可点击“回到最新消息”恢复。系统开启减少动态效果时直接定位。

每轮状态和横线统一位于该轮思考、阶段说明与回答正文之前。运行时状态入口不折叠，思考和操作按顺序直接展示；结束后在同一位置切换为状态与整轮用时的折叠入口。分隔线固定在状态标题下方，运行、结束、展开与收起时均保留；标题使用对话字号和淡灰文字，细小右箭头位于文字右侧。鼠标悬停或键盘聚焦时显现收起状态的箭头，展开时箭头朝下并保持显示；触摸设备始终显示箭头。点击标题或使用 Enter／空格切换，内容带高度和透明度过渡，减少动态效果时关闭动画。工具参数与输出按需读取，收起完成后释放详情；迟到的查询不会重新打开过程。

上下文压缩在实际发生的位置展示独立浅灰状态行，使用细线压缩图标，不进入工具操作分组、计数或详情折叠。相邻压缩批次合并显示：运行时为“正在压缩上下文 · 可能需要几分钟”，所有已加载批次完成且来源明确为自动触发时为“上下文已自动压缩”。回答过程中来源不明的旧记录显示“上下文压缩已结束”，避免把未知来源标为自动压缩成功。失败、取消、中断和断连按实际状态显示；断连或执行已结束但步骤尚未确认时停止加载动画，不推断成功。历史重新展开或重载后复用步骤状态与触发来源，摘要模型正文不进入阶段说明。

输入框在模型选择器左侧仅显示实时上下文圆环，不常驻显示比例。鼠标悬停或键盘聚焦时显示居中的深色三行提示：“背景信息窗口”“xx% 已用”“已用约 xxk 标记，共 xxk”；短数值仅用于显示，不改变原始 Token 统计。容量未知、读取失败及断连显示对应状态，不展示旧百分比。提示不包含压缩或其他操作。百分比以可用输入预算为分母，估算与真实模型 tokenizer 可能存在差异。

输入框支持 `/compact` 手动压缩：输入 `/` 或命令前缀显示候选，Enter 或鼠标点击执行，Tab 补全，Esc 关闭候选。候选采用单行“实时圆环＋压缩＋压缩此聊天的上下文（已使用 xx%）”，不显示双行标题、独立百分比或回车图标；用量未知、受理中或不可执行时展示对应说明。两处共用一份统计查询与执行通知，悬停或候选可见期间共用一个刷新计时器，关闭时释放。流式正文、推理及工具结果通过 Go 数字通知更新，普通草稿通过只读查询叠加，不发送到模型或创建会话；命令候选文字不计入草稿估算。命令本身不作为消息发送；正文中提及 `/compact`、带参数或多行的文字仍作为普通消息。没有已建立的对话、存在活动执行、正在编辑或服务离线时，候选说明不可执行的原因。手动压缩使用当前选中的模型，沿用服务端压缩预算和保留轮次设置；需要有效的模型上下文容量或显式输入预算，配置不足按服务端错误显示，不猜测容量。

手动压缩作为独立执行显示在原有消息之后；确认生成摘要显示“上下文已压缩”，没有较早完整轮次时显示“暂无可压缩的较早对话”。执行期间可用“停止压缩”请求取消，仍以服务端终态为准。受理失败保留命令供重试，受理成功只清除对应命令，其他草稿不变。原始消息和工具记录保留，后续对话使用服务端生效摘要。切换会话、刷新和重启后从执行及压缩步骤恢复状态；失败、取消、中断和结果读取失败不会显示为成功，读取失败可重试读取，不自动重跑压缩。

供应商实际返回推理文本时显示带流光的“思考中”，运行中直接展示且不提供手动折叠按钮；思考步骤结束后显示“已思考”并默认收起。思考文本采用淡色正文，预览最高 140px，超出后可滚动，非边缘位置显示渐隐。未提供独立思考耗时，不将模型请求总耗时充作思考耗时；整轮用时仍使用服务端执行时间。取消和失败保留已收到的部分内容并明确提示。切换会话或重载后可从持久化步骤恢复；缺少字段的旧记录不显示空面板。推理预览沿用有界概述窗口，过长时提示截取；完整记录保留在服务中。不从正文标签猜测或生成推理。
